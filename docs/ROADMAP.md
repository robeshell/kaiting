# 开听路线与工作边界

最后更新：2026-08-02

开听当前以 **1.0.15+18** 作为稳定版本。旧的 GitHub Project「Sound Next Roadmap」已经完成其阶段性任务，现有条目全部归档到 Done；本文件不再充当实时看板，也不再维护一份与 GitHub Issue 重复的任务列表。

## 稳定版能力地图

| 能力域 | 1.0.15 状态 |
| --- | --- |
| 平台 | Android、iOS / iPadOS、macOS、Windows 可用；Web 为预览，Linux 为脚手架 |
| 播放 | 播放模式、可编辑队列、seek、非 Web 连续切歌、会话恢复、睡眠定时 |
| 资料库 | 本地 / WebDAV 扫描、增量识别、搜索、专辑 / 艺人 / 流派、收藏 / 历史 / 播放列表 |
| 网络 | WebDAV Range、认证、临时缓存、固定离线下载、网络错误分类与重试 |
| 体验 | 歌词同步、首次引导、桌面快捷键、响应式布局、Sound 设计系统 |
| 工程 | 测试、静态检查、发布脚本、Pages、macOS 便携式打包链路 |

## 当前边界

以下事项属于稳定版之外的后续候选，不作为 1.0.15 的未完成项：

- 更完整的 Windows 系统媒体控制和原生窗口能力
- 大资料库长期性能基线、资源治理、备份与恢复
- 无障碍、正式本地化和更多真实设备回归
- 第二种远程协议与用户状态云同步（后者暂不做）
- Web 连续播放能力和 Linux 稳定版支持

## 新工作入口

新需求请创建新的 GitHub Issue，并在正文中写明：

1. 目标版本或是否为长期候选
2. 受影响的平台
3. 可验证的验收标准
4. 对应的代码、测试或发布证据

稳定版的详细范围见 [STATUS.md](./STATUS.md)；模块契约见 [ARCHITECTURE.md](./ARCHITECTURE.md)；格式验证见 [AUDIO_FORMAT_MATRIX.md](./AUDIO_FORMAT_MATRIX.md)。
