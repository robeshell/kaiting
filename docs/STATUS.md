# 开听当前状态

最后更新：2026-08-02

当前稳定版本：**1.0.15+18**（用户可见版本 1.0.15）

开听已经进入稳定版本维护阶段。本页记录当前版本已经收敛的产品范围、平台边界和验证口径；它不是实时任务清单。

## 当前版本范围

- 本地目录与带认证的 WebDAV 音乐来源
- 资料库扫描、增量识别、搜索、专辑 / 艺人 / 流派浏览
- 收藏、最近播放、播放历史与播放列表
- 播放队列、播放模式、seek、歌词同步、睡眠定时与会话恢复
- WebDAV 临时缓存与用户主动离线下载
- 统一错误恢复、诊断入口、首次使用引导和桌面键盘操作
- Sound 设计系统、响应式布局与 macOS 原生窗口行为
- 应用内更新与 macOS 便携式发布流程

## 平台边界

| 平台 | 当前定位 | 说明 |
| --- | --- | --- |
| Android | 支持 | 本地来源、WebDAV、后台播放和通知控制已纳入产品范围 |
| iOS / iPadOS | 支持 | Universal 布局、Files 来源和后台播放按系统能力运行 |
| macOS | 支持 | 当前主要回归平台；原生窗口、播放和便携式安装包已验证 |
| Windows | 支持 | 本地 / WebDAV 播放和安装包已纳入；SMTC 等系统集成按平台能力继续维护 |
| Web | 预览 | 用于体验和演示，不承诺与原生端相同的连续播放能力 |
| Linux | 脚手架 | 尚未作为稳定版发布目标 |

## 验证口径

- 代码质量：`dart format`、`flutter analyze`、`flutter test`。
- 当前主机：macOS Debug / Release 构建、播放、WebDAV Range、签名和便携式启动检查。
- 自动化夹具：见 [WEBDAV_FIXTURE.md](./WEBDAV_FIXTURE.md) 和 [AUDIO_FORMAT_MATRIX.md](./AUDIO_FORMAT_MATRIX.md)。
- 不同操作系统的真实设备差异仍按发布前抽检处理，不把某台设备的临时验证记录当作跨平台永久承诺。

## 后续候选

以下内容不再阻塞 1.0.15，也不属于当前版本的已交付承诺：

- 更完整的 Windows 系统媒体控制与原生窗口集成
- 大资料库长期性能基线、备份恢复和资源治理
- 无障碍、正式本地化与更多真实设备回归
- 第二种远程协议、用户状态同步和 Web 能力扩展

新需求请创建新的 GitHub Issue，并明确版本、平台和验收标准；不要恢复历史看板中的旧任务。
